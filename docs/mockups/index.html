Moniuszko — makiety

Statyczne makiety HTML bez logiki. Pokazują układ ekranów opisanych w docs/PLAN.md.

  1. Biblioteka — siatka grafik, filtry, wyszukiwanie, strefa upuszczania, panel metadanych zaznaczonej grafiki.
  2. Import — okno po upuszczeniu kilku plików: postęp, duplikaty, ostrzeżenia sanityzacji.
  3. Kompozycje — lista kompozycji, oznaczenie szkiców utworzonych przez agenta.
  4. Edytor — warstwy, canvas z zaznaczonym obiektem, inspektor, powiadomienie o zmianie przez agenta.
  5. Edytor — panel biblioteki — wstawianie grafik do kompozycji przez przeciągnięcie.
  6. Eksport — wybór trybu: plik samodzielny albo z referencjami.
  7. Ustawienia — foldery workspace, adres MCP i konfiguracja dla agenta.
